# RNA-seq Workflow

This directory documents the RNA-seq preprocessing and differential-expression workflow used for the VIM2/4 expression analyses in the Arabidopsis Ler × Cvi / VIM2/4 project.

The workflow includes two parts:

1. preprocessing raw paired-end RNA-seq FASTQ files into gene-level count tables;
2. downstream DESeq2 analysis of VIM2/4 overexpression lines relative to Col-0 wild type.

This README is intended as a concise workflow-level description. Some scripts contain absolute paths from the original analysis environment and should be updated before rerunning on another system.

---



## Pipeline Overview

| Step | Description | Tool |
|:-----|:------------|:-----|
| Step 0 | FastQC on raw FASTQ files | FastQC |
| Step 1 | Adapter trimming | Trimmomatic (v0.38) |
| Step 2 | Read alignment to TAIR10 | STAR |
| Step 3 | BAM sorting and indexing | Samtools |
| Step 4 | Read counting per gene | HTSeq-count |
| Step 5 | Differential expression analysis | DESeq2 (in R) |

## Files

| File | Description |
|:-----|:------------|
| `run_rnaseq_pipeline.sh` | Bash pipeline: merge FASTQs, QC, trim, align, count (Steps 0-4) |
| `reorder_DEG_for_RIL_paper_new_RNA-seq_2026-05_of_OX__for_group_add_old_sample_col_2026-05.R` | DESeq2 analysis and target-gene barplot generation (Step 5) |
| `DEGs_All_Genes_OX_Col_VIM*_vs_WT_NoFilter.txt` | Full DESeq2 results (all genes) |
| `DEGs_Target_OX_Col_VIM*_vs_WT_NoFilter.txt` | DESeq2 results for 20 methylation-pathway target genes |
| `Combined_VIM2_VIM4_Expression_and_Log2FC_All_OX_Grouped.txt` | Combined VIM2+VIM4 normalized counts and log2FC per OX sample |
| `Barplot_Target_OX_Col_VIM*_vs_WT_NoFilter.pdf` | Barplots of log2FC for target genes |

## Input data

The preprocessing script expects paired-end FASTQ files in a user-defined input directory:

```text
raw_data/total_fastq/
```

Expected FASTQ naming pattern:

```text
*_1.fq.gz
*_2.fq.gz
```

The script automatically identifies sample prefixes, merges multiple sequencing chunks belonging to the same sample when needed, or creates symbolic links when only one chunk is present.

The downstream DESeq2 script expects HTSeq-count output files generated by the preprocessing pipeline, together with older/control count files where required.

---

## Output structure

The preprocessing script writes results under an analysis output directory such as:

```text
analysis_results/
├── 00_merged_fastq/
├── 00_fastqc_raw/
├── 01_trimmed/
├── 02_aligned/
└── 03_counts/
```

| Directory | Description |
|---|---|
| `00_merged_fastq/` | Merged or linked paired-end FASTQ files |
| `00_fastqc_raw/` | FastQC reports for raw FASTQ files |
| `01_trimmed/` | Trimmomatic paired and unpaired trimmed FASTQ files |
| `02_aligned/` | STAR-aligned BAM files, sorted BAM files, and BAM indexes |
| `03_counts/` | HTSeq-count gene-level count files |

## Preprocessing workflow

Run the RNA-seq preprocessing pipeline after updating all input paths, software paths, reference genome paths, and thread settings in `run_rnaseq_pipeline.sh`.

Example:

```bash
bash run_rnaseq_pipeline.sh
```

Main settings used in the script:

| Parameter | Value or description |
|---|---|
| Read type | Paired-end RNA-seq |
| Adapter trimming | Trimmomatic |
| Alignment | STAR |
| Reference genome | Arabidopsis TAIR10 STAR index |
| Gene annotation | Arabidopsis TAIR10 GTF |
| BAM processing | samtools sort and index |
| Read counting | HTSeq-count |
| HTSeq strandedness | `--stranded=reverse` |
| HTSeq feature type | `--type=exon` |
| HTSeq mode | `--mode=union` |

## Differential-expression workflow

The downstream R script performs DESeq2-based group comparisons after combining count files from multiple RNA-seq batches.

Main comparison groups:

| Group | Description |
|---|---|
| `Control_Col_WT` | Col-0 wild-type control |
| `OX_Col_VIM2_Col` | VIM2 overexpression in Col-0 background |
| `OX_Col_VIM4_Col` | VIM4 overexpression in Col-0 background |
| `OX_Col_VIM24_Col` | VIM2 + VIM4 overexpression in Col-0 background |


Run the downstream analysis from this directory after updating paths in the R script:

```bash
Rscript "reorder DEG for RIL paper new RNA-seq 2026-05 of OX  for group add old sample col 2026-05.R"
```

The R script outputs:

- all-gene DESeq2 result tables;
- selected methylation-related target-gene DESeq2 tables;
- target-gene barplots;
- combined VIM2 + VIM4 normalized-expression and log2 fold-change table.

## Selected target genes

The target-gene analysis focuses on selected DNA methylation, demethylation, and VIM/MET1-related genes, including:

```text
MET1, CMT1, CMT2, CMT3, DRM1, DRM2,
VIM1, VIM2, VIM3, VIM4, VIM5, VIM6,
DME, DML2, DML3, ROS1, ROS3, ROS4, ROS5, REF6
```

These genes are used for the target-gene DEG tables and barplots.

## Requirements

- STAR (with TAIR10 genome index)
- Trimmomatic (v0.38)
- Samtools
- HTSeq
- FastQC
- Arabidopsis TAIR10 GTF annotation file
- R with DESeq2, data.table, ggplot2

## Notes

- Paired-end 150 bp reads, sequenced on Illumina NovaSeq 6000 (Novogene).
- Samples with multiple FASTQ slices are automatically merged by the pipeline script.
- HTSeq-count uses `--stranded=reverse --mode=union --type=exon`.
- File paths in scripts need adjustment for local use.
- Raw sequencing files are not stored directly in this GitHub repository.
- Sample-level information is provided in the top-level metadata file:
  `RIL_WGBS_ATAC-seq-RNA-seq_sample_metadata.csv`.
- The count files produced by `run_rnaseq_pipeline.sh` are the direct input for the DESeq2 script.
- Output files from this directory are used for VIM2/4 expression validation and methylation-regulatory gene expression analyses.
